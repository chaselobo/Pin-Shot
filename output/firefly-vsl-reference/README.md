Use **Composition → Reference → Upload video**, as shown in the supplied screenshot. This is a still reference in a video container, not a demonstration of the pull mechanism.

Adobe's composition-reference help lists 5–10 seconds and under 200 MB. The supplied screenshot lists 5–20 seconds and under 200 MB. This five-second clip fits both duration and size limits. The files have been checked locally; acceptance by Firefly has not been tested.
